# What is CloudRader? :material-help-circle-outline:{ .main-color }

**CloudRader** is an open-source initiative dedicated to building a connected ecosystem of independent, self-hostable services. We empower organizations, teams, and communities with tools that work reliably on their own, but even better together.

---

## :material-bullseye-arrow: Core Purpose

Modern software suites are frequently monolithic, expensive, or tied to proprietary cloud vendors. CloudRader solves this by providing modular, single-purpose applications designed for self-hosting:

- :material-calendar-clock: **Reservium** — Room, desk, and shared resource reservation platform.
- :material-package-variant-closed: **Inventarium** — Lightweight organizational asset and equipment tracking (planned).
- :material-shield-key: **Central Identity** — Unified single sign-on across all applications using standard Keycloak OIDC.

---

## :material-lightning-bolt-outline: Key Principles

- **Self-Hostable by Default**: You retain full ownership of your data. Deploy easily anywhere using standard Docker containers.
- **Modular Architecture**: Run only the services your organization actually needs—no monolithic lock-in.
- **Open Standards**: Fully documented REST APIs with OpenAPI specifications, standardized JSON responses, and open protocols.
- **Transparent Development**: Open-source repositories, public roadmaps, and community-driven improvements.
